This page maps the [Maat repository](https://github.com/duongnq2798/maat) folder by folder: what each of its main folders and files holds, and the docs page to read before you open it. It is written for anyone who has run the [Quickstart](/docs/get-started/quickstart) and now opens the code. The code is built and [fork-tested](/docs/help/glossary#fork-test), and the owner deployed the four Maat contracts on Base mainnet ([Base addresses](/docs/reference/base-addresses)). Every folder or file in a table's first column links to its place on GitHub, and [`docs-content.test.ts`](https://github.com/duongnq2798/maat/blob/main/web/test/docs-content.test.ts) fails when one of them is not in the repository, when a top-level folder is missing from the first table, or when the page does not name a file at the root.

## Top-level folders

| Folder | What is in it | Read first |
| --- | --- | --- |
| [`contracts/`](https://github.com/duongnq2798/maat/tree/main/contracts) | The Foundry project: the [vault](/docs/help/glossary#vault), its calendar, libraries and adapters, the deploy script and the Solidity tests | [Security model](/docs/security/model) |
| [`agent/`](https://github.com/duongnq2798/maat/tree/main/agent) | The TypeScript agent: its source, its unit and fork tests, and its scripts | [How a decision is made](/docs/get-started/how-a-decision-is-made) |
| [`web/`](https://github.com/duongnq2798/maat/tree/main/web) | The website: the landing page, the Right now on Base page (`/now`), the Weekend Gap Index (`/gap-index`), the mainnet ledger (`/ledger`) and this docs center, built as a static Next.js export, with their tests | [Parity tests: the site and these docs](/docs/security/testing#parity-tests-the-site-and-these-docs) |
| [`deployments/`](https://github.com/duongnq2798/maat/tree/main/deployments) | `go-live.md`, the [owner](/docs/help/glossary#owner)'s go-live runbook, which takes the vault from the deploy and funding through its first `Decision` events to the handover to the agent; and `README.md`, the deploy reference it draws on and the table of deployed addresses, which lists the four Maat contracts on Base mainnet | [Deploy your own vault](/docs/guides/deploy-your-own-vault) |
| [`skills/`](https://github.com/duongnq2798/maat/tree/main/skills) | `maat-market-guard`, the read-only check other agents call before they trade, in BankrBot's skills format: its `SKILL.md`, which the site serves at [`/skill.md`](/skill.md), its catalog entry, and a Node script with no dependencies that asks the vault's calendar or the vault's `previewIntent` and prints the typed reason, with an offline selftest | [Refusal codes](/docs/concepts/refusal-codes) |
| [`ops/`](https://github.com/duongnq2798/maat/tree/main/ops) | `journal/`, the journal publisher: a Node script the owner starts beside the agent's restart loop. Every 15 minutes it appends the public fields of the agent's new [journal](/docs/help/glossary#journal) rows to the public `agent-journal` branch and pushes them with a plain push, never a force push; its `README.md` says how to start and stop it on Windows | [Read the journal](/docs/guides/run-the-agent#read-the-journal) |
| [`scripts/`](https://github.com/duongnq2798/maat/tree/main/scripts) | `recount.mjs`, which rebuilds the brief lines of the site's `/proof` page from Base alone: it reads the deployments table from `deployments/README.md` and the team, sent-transaction, hop-stop, hide and bounty lists from `web/content/`, then every `Brief` log, the team trace the page runs (`web/app/(site)/proof/team.ts`) and the Verified Accounts from a keyless RPC. It runs on Node.js 24 and has no dependency | [Count the briefs](/docs/guides/brief-the-agent#count-the-briefs) |
| [`docs/`](https://github.com/duongnq2798/maat/tree/main/docs) | The design specs and the implementation plans that each part of Maat was built from, in `docs/superpowers`, and the README's screenshots, in `docs/assets/readme` | [Changelog](/docs/help/changelog), which links each milestone's spec or plan |
| [`.github/`](https://github.com/duongnq2798/maat/tree/main/.github) | The CI workflow `workflows/ci.yml`, which runs the offline suites, the secret scan and a lint of the workflow on every pull request and every push to `main`; `scripts/ci-counts.mjs`, which writes the counts each runner reports into the run's summary, with its tests; `workflows/live-fork.yml`, which runs the live fork suites against the deployed vault once a day, and `scripts/live-fork.mjs`, which picks its block and RPC and runs the suites, rerunning once a failure that came with RPC errors, with its tests; and `dependabot.yml`, which proposes updates to the pinned actions once a month | [Run the tests](/docs/guides/run-the-tests) |

At the root sit `README.md`, the project's overview; `SECURITY.md`, how to report a security problem privately; `LICENSE`, the MIT License; `.gitattributes`, which checks text files out with LF on every OS; `.gitignore`, which keeps build and test output, `node_modules`, the agent's default data folder `agent/data/`, `.env` files, Foundry's deploy logs from dry runs and from Anvil's default chain, and the maintainers' working folders out of git; `.gitmodules`, which names the Foundry libraries that `contracts/lib` pulls in as git submodules; and `.gitleaks.toml`, the config of the secret scan that CI runs.

| [`contracts/src/IMandateVaultEvents.sol`](https://github.com/duongnq2798/maat/blob/main/contracts/src/IMandateVaultEvents.sol) | The events the vault emits, `Decision` among them | [Events](/docs/reference/events) |

## Agent

The TypeScript agent, its tests and its scripts. Run the npm commands in `agent/`.

| Folder or file | What is in it | Read first |
| --- | --- | --- |
| [`agent/src/main.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/main.ts) | The entry point that `npm run agent` starts. It loads the settings, takes the lock, then runs one [round](/docs/help/glossary#round) or the loop | [`npm run agent`](/docs/reference/agent-scripts#agent) |
| [`agent/src/config.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/config.ts) | Reads the agent's own settings from the environment, fills in the defaults, and stops the start with `invalid agent config` when one is missing or wrong. The Claude and CDP keys are read by their SDKs instead | [Agent configuration](/docs/reference/agent-configuration) |
| [`agent/src/runtime.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/runtime.ts) | Builds, at the start, what every round uses: the Base client, the Claude proposer, the state store and the [journal](/docs/help/glossary#journal) in the data folder, and the sender. Only [live mode](/docs/help/glossary#live-mode) has a sender: the agent is built to connect the [CDP Server Wallet](/docs/help/glossary#cdp-server-wallet) account named by `CDP_ACCOUNT_NAME`, stop unless its address is `MAAT_EXECUTOR`, and wrap it in `GuardedSender`. In [dry-run mode](/docs/help/glossary#dry-run), the default, or with `--dry-run`, there is no sender and no CDP call | [Run a dry run](/docs/guides/run-the-agent#run-a-dry-run), then [Switch to live mode and run one round](/docs/guides/run-the-agent#switch-to-live-mode-and-run-one-round) |
| [`agent/src/policy.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/policy.ts) | The treasury policy: each stock's target weight, the cash reserve and the [runway](/docs/help/glossary#runway), and the trades it suggests to Claude | [The treasury loop](/docs/concepts/treasury-loop) |
| [`agent/src/intent.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/intent.ts) | Turns each proposal into the onchain `Intent`: its id and its action; its token; its amount in [raw units](/docs/help/glossary#raw-amount), cut where needed to the vault's balance, debt or collateral; a `minOut` of 0, so a swap's minimum is the vault's own [slippage floor](/docs/help/glossary#slippage-floor); the payee `MAAT_EXPENSE_PAYEE` for a bill payment, and the zero address otherwise; and the hash of its [rationale blob](/docs/help/glossary#rationale-blob). A proposal that does not fit, such as one for a stock the vault does not list, gets an error instead | [Send intents from your own code](/docs/guides/deploy-your-own-vault#send-intents-from-your-own-code) |
| [`agent/src/refusals.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/refusals.ts) | The gate the agent is built to apply to each [preview](/docs/help/glossary#preview): send the intent when the preview is `OK`, send it once per NYSE date for each [refusal](/docs/help/glossary#refusal) reason worth recording onchain (a `MARKET_CLOSED` once per closed phase of that date), and send nothing otherwise. In dry-run mode, the default, the agent sends nothing | [How the agent reacts](/docs/concepts/refusal-codes#how-the-agent-reacts) |
| [`agent/src/chain/`](https://github.com/duongnq2798/maat/tree/main/agent/src/chain) | Reads the vault, its stocks, their feeds and its Aave position at one block, and previews an intent | [Step 1: read the vault](/docs/get-started/how-a-decision-is-made#step-1-read-the-vault), then [Read the vault now](/docs/guides/watch-decisions-onchain#read-the-vault-now), which reads the vault, its balances and its Aave position with `cast` at the latest block |
| [`agent/src/llm/`](https://github.com/duongnq2798/maat/tree/main/agent/src/llm) | The Claude proposer, its prompt, the schema every proposal must fit, and the token prices that turn each answer into its share of the [compute bill](/docs/help/glossary#compute-bill) | [Step 2: the policy and Claude](/docs/get-started/how-a-decision-is-made#step-2-the-policy-and-claude) |
| [`agent/src/exec/`](https://github.com/duongnq2798/maat/tree/main/agent/src/exec) | The calldata and gas limits, the [Builder Code](/docs/help/glossary#builder-code-erc-8021) suffix, `GuardedSender`, which sends nothing but the vault's `execute`, `syncMultiplier` or `notifyRevenue`, and the [CDP Server Wallet](/docs/help/glossary#cdp-server-wallet) sender and its policy | [Step 3: preview and send](/docs/get-started/how-a-decision-is-made#step-3-preview-and-send) |
| [`agent/src/loop/`](https://github.com/duongnq2798/maat/tree/main/agent/src/loop) | `runOnce.ts`, one round of the loop; the scheduler that repeats it; and the lock that keeps a second agent off the same data folder | [The loop in four steps](/docs/get-started/how-a-decision-is-made#the-loop-in-four-steps) |
| [`agent/src/ledger/`](https://github.com/duongnq2798/maat/tree/main/agent/src/ledger) | The state store, `state.json`, and the [journal](/docs/help/glossary#journal), `journal.jsonl`, both in the data folder | [Read the journal](/docs/guides/run-the-agent#read-the-journal), then [What the agent keeps in its data folder](/docs/guides/run-the-agent#what-the-agent-keeps-in-its-data-folder) |
| [`agent/src/rationale/`](https://github.com/duongnq2798/maat/tree/main/agent/src/rationale) | The [rationale blob](/docs/help/glossary#rationale-blob) and its checks | [`npm run verify`](/docs/reference/agent-scripts#verify) |
| [`agent/src/abi/`](https://github.com/duongnq2798/maat/tree/main/agent/src/abi) | The contract ABIs the agent calls the chain with, generated from the compiled contracts | [`npm run gen:abi`](/docs/reference/agent-scripts#genabi) |
| [`agent/test/`](https://github.com/duongnq2798/maat/tree/main/agent/test) | The unit tests, which run against fakes of the chain, Claude and the CDP wallet. `fakes/` holds the fake chain, receipts and sender | [Agent unit tests](/docs/guides/run-the-tests#agent-unit-tests) |
| [`agent/test/integration/`](https://github.com/duongnq2798/maat/tree/main/agent/test/integration) | The agent's fork test. It starts the Base build of Anvil on a mainnet fork, deploys the contracts there and runs agent rounds against them, with fixed proposals in place of Claude. `fork-gas.json` is the committed gas log | [Reproduce the fork run](/docs/guides/reproduce-the-fork-run) |
| [`agent/scripts/`](https://github.com/duongnq2798/maat/tree/main/agent/scripts) | `cdp-setup.ts`, which the owner runs once to create the executor account and its policy; `first-decision.ts`, which builds one `BUY` intent offline for the owner to send; `gen-abis.ts`, behind `npm run gen:abi`; `verify-decision.ts`, behind `npm run verify`; and `smoke-claude.ts`, which makes one paid Claude call | [Script files](/docs/reference/agent-scripts#script-files) |
