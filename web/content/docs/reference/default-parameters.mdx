A default is a value the code uses until someone changes it. This page lists the defaults that the vault, the calendar and the agent ship with, each with its unit and the file that sets it, so you can find a number without reading the code. A last table holds figures that look like defaults and are not: measurements, counts and plans. The vault and the agent are built and fork-tested, and nothing is deployed, so these are the defaults of the code, not of a running deployment. The values come from the same fact list as the rest of the docs, and tests compare the ones the repository can prove with the code that sets them.

## Vault and mandate

The rows named `mandate.*` are the default mandate that `MaatConfig.defaultMandate()` builds for the deploy script. The owner can change any [mandate](/docs/concepts/mandate) field later, through the [timelock](/docs/help/glossary#timelock). The other rows are constants and bounds in the contract code, so only a new deployment changes them.

## Calendar

These come from `MarketCalendar.sol`. The session times and the feed edge are constants in New York time, and the offsets are the rule the contract uses to turn UTC into New York time. The early close is the time that the constructor gives to the early closes it ships. The owner can add holidays and move a close earlier, but cannot make the calendar looser. The dates it ships are listed on [MarketCalendar](/docs/reference/market-calendar#shipped-holidays-and-early-closes).

## Agent

`maxTxPerDay` and `dailyComputeUsd` are the defaults of two environment variables, `MAAT_MAX_TX_PER_DAY` and `MAAT_DEFAULT_DAILY_COMPUTE_USD`, so you change them in `.env` ([Agent configuration](/docs/reference/agent-configuration)). The other rows are constants in the agent's source, such as `DEFAULT_POLICY` in `agent/src/policy.ts`. `main.ts` passes no override, so changing one of them means editing the code.
