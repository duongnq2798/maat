`MarketCalendar` answers one question for the [vault](/docs/help/glossary#vault): is the market open at this moment? It works in New York time, applies daylight saving by rule, and ships with a few holidays and early closes. Its owner can only make it stricter, by adding a holiday or moving a close earlier. A calendar that is looser has to be a new contract, switched in through the [mandate](/docs/help/glossary#mandate) and its [timelock](/docs/help/glossary#timelock). This page lists each function and the dates the constructor ships. Each entry also gives the function's selector, the first four bytes of the keccak-256 hash of its canonical ABI signature (the name and the parameter types, with an enum as `uint8`): the calldata of a call to the function starts with it. The contract is built and fork-tested and has not been audited ([What Maat does not claim](/docs/security/not-claimed#unaudited)). The owner deployed Maat's own calendar on Base mainnet, and [Base addresses](/docs/reference/base-addresses) gives its address.

To call or decode the calendar from code without building the repo, use its <a href="/data/abi/MarketCalendar.json">ABI (JSON)</a>: `marketCalendarAbi` from [`agent/src/abi/generated.ts`](https://github.com/duongnq2798/maat/blob/main/agent/src/abi/generated.ts), which [`gen:abi`](/docs/reference/agent-scripts#genabi) writes from the compiled contracts.

## Functions

The contract's tests are in [MarketCalendar.t.sol](https://github.com/duongnq2798/maat/blob/main/contracts/test/MarketCalendar.t.sol) and [MarketCalendarVectors.t.sol](https://github.com/duongnq2798/maat/blob/main/contracts/test/MarketCalendarVectors.t.sol). In the first, `test_ownerCanOnlyMakeItStricter` covers the two owner functions, and `test_dstBoundaries`, `test_regularSession`, `test_feed245Session` and `test_holidaysAndEarlyClose` cover the time rules. One test per 2027 date after New Year, such as `test_goodFriday2027IsClosed` and `test_dayAfterThanksgiving2027ClosesEarly`, checks the shipped 2027 closures. The second checks the contract against vectors computed outside Solidity: `etOffsetSeconds` at every daylight saving change from 2007 to 2100, and `isHoliday`, `earlyCloseMin` and, at fixed New York times, `isOpen` on every shipped date, 2026-12-24's <Fact name="earlyClose" /> close included ([Calendar vectors](/docs/security/testing#calendar-vectors)).

### addHoliday

<Fn contract="MarketCalendar" name="addHoliday" />

Only the owner may call it, and any other caller [reverts](/docs/help/glossary#revert) with `NotOwner`. It marks the New York calendar day given by `y`, `m` and `d` (year, month, day) as a holiday and emits `HolidayAdded` with the day number. A holiday closes the day in both [session modes](/docs/help/glossary#session-mode). Nothing removes a holiday, which is one half of why the calendar can only get stricter. Adding a day that is already a holiday emits the event again and changes nothing, and the function does not validate the date.

### setEarlyClose

<Fn contract="MarketCalendar" name="setEarlyClose" />

Only the owner may call it. It sets the early close of one New York day to `closeMin` minutes after midnight and emits `EarlyCloseSet`. The value must be after the open (<Fact name="nyseOpen" />) and before the regular close (<Fact name="nyseClose" />) of the [NYSE session](/docs/help/glossary#nyse-session), and earlier than the day's existing early close if it has one. Otherwise the call reverts with `InvalidClose`, so a close can only move earlier. An early close applies to the `REGULAR` mode only: `FEED_24_5` ignores it.

### etOffsetSeconds

<Fn contract="MarketCalendar" name="etOffsetSeconds" />

Returns the seconds to subtract from a UTC timestamp to get New York time: <Fact name="etOffsetHours.dst" /> during US daylight saving time and <Fact name="etOffsetHours.standard" /> otherwise. Daylight saving runs from the second Sunday in March to the first Sunday in November, and the contract writes the two switch instants in UTC. The rule is fixed in the code, so it needs no yearly update, and it takes the year from the UTC date of the timestamp. [Market hours](/docs/concepts/market-hours#new-york-time-onchain) explains it further.

### localTime

<Fn contract="MarketCalendar" name="localTime" />

Converts a UTC timestamp to New York calendar terms. It returns `etDay`, the day number counted from the Unix epoch in New York time, the weekday with zero for Sunday and six for Saturday, and the minute of the day, counted from local midnight. `isOpen` uses it, and so does the vault when it works out whether the [de-risk window](/docs/help/glossary#de-risk-window) is on. It is a pure function, so it can be called with any timestamp.

### isOpen

<Fn contract="MarketCalendar" name="isOpen" />

Returns true when the market is open at the UTC timestamp `ts` under `mode`. A holiday is closed in both modes. `REGULAR` is open on weekdays from <Fact name="nyseOpen" /> up to, but not including, the close, which is the day's early close if one is set and <Fact name="nyseClose" /> otherwise. `FEED_24_5` is closed all Saturday, open on Sunday from <Fact name="feedEdge" />, open all day from Monday to Thursday, and open on Friday until <Fact name="feedEdge" />. The vault calls it inside a try/catch, so a calendar that reverts counts as closed.

### owner

<Fn contract="MarketCalendar" name="owner" />

The address that may call `addHoliday` and `setEarlyClose`. It is set in the constructor and cannot be changed, and the constructor reverts with `ZeroAddress` for the zero address. The calendar's owner is separate from the vault's owner.

### isHoliday

<Fn contract="MarketCalendar" name="isHoliday" />

True when the New York day with this day number is a holiday. `localTime` gives the number for a timestamp, and `HolidayAdded` logs it. The vault also reads it for the next day, to find the last session day before a holiday.

### earlyCloseMin

<Fn contract="MarketCalendar" name="earlyCloseMin" />

The early close of a New York day, in minutes after midnight, or zero when the day has none. `isOpen` uses it as the close in `REGULAR` mode whenever it is not zero.

## Shipped holidays and early closes

The constructor ships with <Fact name="calendarPreload.holidays" /> holidays and <Fact name="calendarPreload.earlyCloses" /> early closes, so the calendar is useful the day it is deployed. Each early close is at <Fact name="earlyClose" />. The table lists them by date, and the excerpt below is the constructor they come from. The 2027 dates are from the NYSE holiday calendar on nyse.com, read on 2026-11-16.

| Date | Kind | Close time |
| --- | --- | --- |
| 2026-11-26 | Holiday (Thanksgiving) | Closed all day |
| 2026-11-27 | Early close | <Fact name="earlyClose" /> |
| 2026-12-24 | Early close | <Fact name="earlyClose" /> |
| 2026-12-25 | Holiday (Christmas) | Closed all day |
| 2027-01-01 | Holiday (New Year) | Closed all day |
| 2027-01-18 | Holiday (Martin Luther King Jr. Day) | Closed all day |
| 2027-02-15 | Holiday (Washington's Birthday) | Closed all day |
| 2027-03-26 | Holiday (Good Friday) | Closed all day |
| 2027-05-31 | Holiday (Memorial Day) | Closed all day |
| 2027-06-18 | Holiday (Juneteenth, observed) | Closed all day |
| 2027-07-05 | Holiday (Independence Day, observed) | Closed all day |
| 2027-09-06 | Holiday (Labor Day) | Closed all day |
| 2027-11-25 | Holiday (Thanksgiving) | Closed all day |
| 2027-11-26 | Early close | <Fact name="earlyClose" /> |
| 2027-12-24 | Holiday (Christmas, observed) | Closed all day |

```solidity title="contracts/src/MarketCalendar.sol#L30-L49"
    constructor(address owner_) {
        if (owner_ == address(0)) revert ZeroAddress();
        owner = owner_;
        _addHoliday(2026, 11, 26); // Thanksgiving
        _addHoliday(2026, 12, 25); // Christmas
        _addHoliday(2027, 1, 1); // New Year
        // 2027 closures from the NYSE holiday calendar on nyse.com, read 2026-11-16.
        _addHoliday(2027, 1, 18); // Martin Luther King Jr. Day
        _addHoliday(2027, 2, 15); // Washington's Birthday
        _addHoliday(2027, 3, 26); // Good Friday
        _addHoliday(2027, 5, 31); // Memorial Day
        _addHoliday(2027, 6, 18); // Juneteenth (observed)
        _addHoliday(2027, 7, 5); // Independence Day (observed)
        _addHoliday(2027, 9, 6); // Labor Day
        _addHoliday(2027, 11, 25); // Thanksgiving
        _addHoliday(2027, 12, 24); // Christmas (observed)
        _setEarlyClose(2026, 11, 27, 780); // 13:00
        _setEarlyClose(2026, 12, 24, 780);
        _setEarlyClose(2027, 11, 26, 780);
    }
```

No other date is in the contract. The owner adds later ones with `addHoliday` and `setEarlyClose`, and a day that is missing counts as an ordinary session, as [What happens if a holiday is missing](/docs/concepts/market-hours#what-happens-if-a-holiday-is-missing) explains.
