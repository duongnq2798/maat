## Simulator

**Dates.** From 2026-11-08 to 2026-11-16. The first commit is `4bf219b`, the design spec, and the last is `72ceba3`. The branch `feat/try-simulator` was merged as pull request #1 in `8608b7d` on 2026-11-16.

**Scope.** The "Try to make it say no" section of the landing page, linked from the navigation and the hero: a [simulator](/#try) of the default [mandate](/docs/help/glossary#mandate) that runs in the browser. It is a simulation, not the contract, and it handles `BUY` only. A visitor picks a basket token or one outside the mandate, an amount, and a New York time on a date from the fork day to the last holiday or early close the calendar lists, and the page shows the [nine checks](/docs/concepts/nine-checks) in the [vault](/docs/help/glossary#vault)'s order and the [reason](/docs/help/glossary#reason) it would return. It computes the token list, the market session (through a TypeScript port of `MarketCalendar` in `REGULAR` [session mode](/docs/help/glossary#session-mode), with the holidays and early closes the calendar lists), the per-trade and daily size caps, the vault's USDC balance and the weight limit. The other checks (token not paused, transfer policy, feed freshness, multiplier stable and pool premium) stay at values measured on the Base fork at the fork block, with the feed age measured for one token only and the other feeds assumed fresh. Execute adds the [intent](/docs/help/glossary#intent) to that day's list of decisions. A day starts with the fork vault's USDC and no stock, and holdings are valued at cost where the vault uses the Chainlink price. A share link holds the scenario, and the page recomputes every verdict from it. The simulator reads no chain and sends no transaction, and the page says that the contracts decide. Parity tests check the calendar port against the Foundry vectors of `MarketCalendar.t.sol` and the new facts (the calendar, the basket and the fork vault's USDC) against `MarketCalendar.sol`, `MaatConfig.sol` and the fork run's `deploy.ts`, and unit, component and browser tests drive the simulator.

**Read.** [The simulator design spec](https://github.com/duongnq2798/maat/blob/main/docs/superpowers/specs/2026-11-08-mandate-simulator-design.md), [the plan](https://github.com/duongnq2798/maat/blob/main/docs/superpowers/plans/2026-11-08-mandate-simulator.md), [`web/content/simulator.ts`](https://github.com/duongnq2798/maat/blob/main/web/content/simulator.ts), [`web/content/calendar.ts`](https://github.com/duongnq2798/maat/blob/main/web/content/calendar.ts) and [`web/components/Simulator.tsx`](https://github.com/duongnq2798/maat/blob/main/web/components/Simulator.tsx).

## Agent runtime

**Dates.** 2026-11-06. The first commit is `16903ae`, the plan, and the last is `1193248`. The branch was merged in `4700f47` on 2026-11-07.

**Scope.** The TypeScript agent in `agent/`: a [vault](/docs/help/glossary#vault) reader pinned to one block, a rule-based policy, the Claude proposer, a [preview](/docs/help/glossary#preview) from the [executor](/docs/help/glossary#executor), a guarded sender that adds the [Builder Code](/docs/help/glossary#builder-code-erc-8021), the [CDP Server Wallet](/docs/help/glossary#cdp-server-wallet) sender, the [journal](/docs/help/glossary#journal), the scheduler and a [fork test](/docs/help/glossary#fork-test) that runs the whole [round](/docs/help/glossary#round). The Claude proposer and the CDP sender are tested against fakes only, and the fork run uses a scripted proposer and a local sender.

**Read.** [Plan 2B](https://github.com/duongnq2798/maat/blob/main/docs/superpowers/plans/2026-11-06-maat-plan-2b-agent-runtime.md) and [`agent/`](https://github.com/duongnq2798/maat/tree/main/agent).
