# Owner clips

Drop the two Basescan screen recordings here, as `.mp4`, `.mov`, `.webm` or `.mkv`:

- `basescan-decision-log`: a `Decision` event in the `MandateVault`'s Events tab (beat 2);
- `basescan-input-utf8`: an agent Decision's input data viewed as UTF-8 (beat 4).

git ignores every other file in this folder, so a recording is never committed. `film/README.md` says how to record
them and how to render.
