# Maat — Web W1: Landing & Brand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Maat landing page in `web/`, matching comp v2 "Signal":
- Interactive Decision engine in the hero (Sat → Refused · `MARKET_CLOSED`, Thu → Allowed).
- Ledger with 4 fork rows, always carrying a source label.
- Every number comes from `content/facts.ts`, with parity tests that check it directly against the contract and the fork test.
- Brand set: logo, favicon, OG image, avatar and X banner.
- Builds to a static export. The owner only needs to import it into Vercel.

**Architecture:**
- The page is Server Components rendered statically at build time. There are only two client islands, `DecisionEngine` and `LedgerTable`.
- Data lives in `web/content/`:
  - `facts.ts`: every number has a `source`;
  - `decisions.ts`: `DecisionRow` has a `source`, so W2 can swap in mainnet events without changing the UI;
  - `engine.ts`: the two moments of the Decision engine, built from the ledger rows themselves.
- The logo has a single geometric source (`brand/mark.ts`). The `Mark` component and the brand script (satori + resvg) both draw from it.
- Three layers of checks:
  - vitest: logic, copy, parity with the contract;
  - `check:out`: reads the exported HTML;
  - Playwright: smoke test on `out/` at 360/768/1440 px.

### Decisions made while writing the plan

1. **Font:** use the `geist` package (`geist/font/sans`, `geist/font/mono`) instead of `next/font/google`. Same Geist font, self-hosted, auto-preloaded, and the build needs no network. Spec §2.2 only requires "self-hosted, no call to Google at runtime".
2. **Contrast** (to reach Lighthouse Accessibility = 100, spec §1):
   - SKIP rows in the Decision engine use color `ink-2` instead of `opacity: .55`;
   - check ordinal numbers use `ink-2` instead of `ink-3`.

   Opacity 0.55 and `ink-3` on a white background are both below 4.5:1. `ink-3` is used only on dark backgrounds (code panel).
3. **Narrow screens:**
   - the middle cell of a check row is flex-wrap, so the detail drops below the label when space runs out;
   - every key/value grid uses `auto minmax(0,1fr)`, and values are allowed to wrap.

   On desktop it still matches the comp.
4. **Ledger:** use a real `<table>` instead of the comp's div grid. The table sits in its own horizontal scroll region.
5. **Do not create `twitter-image.png`:** Next uses the OG image automatically.
6. **No ESLint in W1:** Next 16 has dropped `next lint`. Typecheck and tests are enough.
7. **`metadataBase`** is taken in this order: `NEXT_PUBLIC_SITE_URL`, then `https://${VERCEL_PROJECT_PRODUCTION_URL}`, finally `http://localhost:3000`.
8. **The Decision engine replays two ledger rows:** the refused BUY row and the allowed BUY row. The engine and the ledger therefore cannot drift apart.
9. **`components/ui/` contains only `Mark`, `SectionHeading`, `CodePanel`.** Spec §5.2 additionally lists Pill, Card, Eyebrow, SourceNote. The first three are CSS classes (`.pill-dark`, `.card`, `.eyebrow`). SourceNote is a note paragraph that lives directly inside `LedgerTable`, since it is used only there.
10. **E2E runs at 4 sizes:** 360, 768, 1440 and 1920 px. Spec §8 names the first three sizes, while §1 requires up to 1920 px.

## Review Focus

1. **360 px phone:** long mono details (`$20 ≤ $50 · $100/day`, `8 h before Fri 20:00 ET`, `[from mainnet tx]`) must not be clipped inside a card with `overflow:hidden`, and must not overflow outside it either. They must wrap.
   → Task 10: e2e checks that every `.card` has `scrollWidth ≤ clientWidth` at all 4 sizes.
2. **Screen reader user presses the toggle:** the `role="status"` region must **keep the same DOM node** across every change. If it is remounted, the change will not be read out.
   → Task 4: test that the node before and after the click is the same node.
3. **Pressing the already selected button again:** the animation replays, the state does not change, `aria-pressed` stays correct.
   → Task 4: test.
4. **User enables reduced motion:** sees the final state immediately. There is nowhere with `opacity:0` outside `@keyframes`.
   → Task 1: CSS test. Task 10: e2e uses `emulateMedia({ reducedMotion: "reduce" })`.
5. **No JS** (crawlers, X's link-preview bot, before hydration): the exported HTML must already contain the Saturday state (Sat selected, Refused, `MARKET_CLOSED`), and `og:image` must be an absolute URL.
   → Task 9: `checkExport` checks `out/index.html`. It reads `data-verdict` and `data-reason` directly in the `role="status"` region. The word "Refused" alone is not enough, since the ledger filter button also contains that word.

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";
import { fileURLToPath } from "node:url";

/** Repo root: web/test/helpers → ../../../ */
export const REPO_ROOT = fileURLToPath(new URL("../../../", import.meta.url));

export function readRepo(rel: string): string {
  return readFileSync(join(REPO_ROOT, rel), "utf8");
}

function stripComments(src: string): string {
  return src.replace(/\/\*[\s\S]*?\*\//g, "").replace(/\/\/[^\n]*/g, "");
}

export function enumMembers(src: string, name: string): string[] {
  const m = new RegExp(`enum\\s+${name}\\s*\\{([^}]*)\\}`).exec(stripComments(src));
  if (!m?.[1]) throw new Error(`enum ${name} not found`);
  return m[1]
    .split(",")
    .map((s) => s.trim())
    .filter(Boolean);
}

const UNITS: Record<string, number> = { seconds: 1, minutes: 60, hours: 3600, days: 86_400, weeks: 604_800 };

/** Solidity or TS number literal: "1.5e18", "8 hours", "1 days", "53_551_627n". */
export function solidityNumber(literal: string): number {
  const [num = "", unit, ...rest] = literal.trim().split(/\s+/);
  if (rest.length > 0) throw new Error(`unexpected literal: ${literal}`);
  const n = Number(num.replace(/_/g, "").replace(/n$/, ""));
  if (!Number.isFinite(n)) throw new Error(`not a number literal: ${literal}`);
  if (unit === undefined) return n;
  const k = UNITS[unit];
  if (k === undefined) throw new Error(`unknown unit in ${literal}`);
  return n * k;
}

/** Right-hand side of the first `NAME = value;`. */
export function constantValue(src: string, name: string): string {
  const m = new RegExp(`\\b${name}\\s*=\\s*([^;]+);`).exec(stripComments(src));
  if (!m?.[1]) throw new Error(`constant ${name} not found`);
  return m[1].trim();
}

/** Every `field: value` in struct literals, in source order. */
export function fieldValues(src: string, field: string): string[] {
  return [...stripComments(src).matchAll(new RegExp(`\\b${field}\\s*:\\s*([^,\\n})]+)`, "g"))].map((m) =>
    (m[1] ?? "").trim(),
  );
}

export interface ParsedParam {
  type: string;
  indexed: boolean;
  name: string;
}

export function eventParams(src: string, name: string): ParsedParam[] {
  const m = new RegExp(`event\\s+${name}\\s*\\(([^)]*)\\)`).exec(stripComments(src));
  if (!m?.[1]) throw new Error(`event ${name} not found`);
  return m[1].split(",").map((p) => {
    const parts = p.trim().split(/\s+/);
    return { type: parts[0] ?? "", indexed: parts.includes("indexed"), name: parts[parts.length - 1] ?? "" };
  });
}

export function pragmaVersion(src: string): string {
  const m = /pragma solidity\s+([^;]+);/.exec(src);
  if (!m?.[1]) throw new Error("pragma not found");
  return m[1].trim();
}
```

```ts
import { type DecisionRow, getDecisions, intentLabel } from "./decisions";
import { FACTS } from "./facts";
import { dayLabel, formatInt } from "./format";
import type { ReasonCode } from "./reasons";

export type MomentId = "sat" | "thu";
export type CheckMark = "PASS" | "FAIL" | "SKIP";

export interface EngineCheck {
  readonly label: string;
  readonly detail: string;
  readonly mark: CheckMark;
}

export interface EngineMoment {
  readonly id: MomentId;
  readonly toggleLabel: string;
  readonly intent: string;
  readonly when: string;
  readonly checks: readonly EngineCheck[];
  readonly allowed: boolean;
  readonly reason: ReasonCode;
  readonly outcome: string;
}

/** Spec §3.1 order. The vault stops at the first failing check, so later ones are never reached. */
export const CHECK_LABELS = [
  "Token allowed",
  "Token not paused",
  "Vault policy",
  "Market session",
  "Feed freshness",
  "Multiplier stable",
  "DEX premium",
  "Size limits",
  "Concentration",
] as const;

function run(details: readonly string[], failAt?: number): EngineCheck[] {
  return CHECK_LABELS.map((label, i): EngineCheck => {
    if (failAt === undefined || i < failAt) return { label, detail: details[i] ?? "", mark: "PASS" };
    if (i === failAt) return { label, detail: details[i] ?? "", mark: "FAIL" };
    return { label, detail: "not reached", mark: "SKIP" };
  });
}

// The engine replays two rows of the fork ledger, so the two can never disagree.
const rows = getDecisions();
function pick(match: (r: DecisionRow) => boolean, what: string): DecisionRow {
  const row = rows.find(match);
  if (!row) throw new Error(`the fork ledger has no ${what}`);
  return row;
}
function gasOf(r: DecisionRow): string {
  if (r.gasUsed === undefined) throw new Error(`no gas recorded for ${intentLabel(r)}`);
  return formatInt(r.gasUsed);
}

const refused = pick((r) => !r.allowed && r.action === "BUY", "refused BUY");
const bought = pick((r) => r.allowed && r.action === "BUY", "allowed BUY");
const m = FACTS.mandate.value;
const satDay = dayLabel(FACTS.forkDay.value, FACTS.weekendOffsetDays.value);
const thuDay = dayLabel(FACTS.forkDay.value);
const time = FACTS.forkTimeEt.value;

export const MOMENTS: Readonly<Record<MomentId, EngineMoment>> = {
  sat: {
    id: "sat",
    toggleLabel: satDay,
    intent: intentLabel(refused),
    when: `${satDay} · weekend`,
    checks: run([`${refused.symbol} in mandate`, "transfers active", "authorized", "Saturday · NYSE closed"], 3),
    allowed: false,
    reason: refused.reason,
    outcome: `Decision logged · gas ${gasOf(refused)}`,
  },
  thu: {
    id: "thu",
    toggleLabel: `${thuDay} · ${time}`,
    intent: intentLabel(bought),
    when: `${thuDay} · ${time} ET`,
    checks: run([
      `${bought.symbol} in mandate`,
      "transfers active",
      "authorized",
      `${m.sessionMode} · open`,
      `${FACTS.feedAgeSec.value}s ≤ ${m.maxStalenessSec}s`,
      `no change ${m.multiplierCooldownSec / 3600}h`,
      `${FACTS.premiumsBps.value.NVDAc} ≤ ${m.maxPremiumBps} bps`,
      `$${bought.amountUsd} ≤ $${m.perTradeCapUsd} · $${m.dailyCapUsd}/day`,
      `weight ≤ ${m.maxWeightBps / 100}%`,
    ]),
    allowed: true,
    reason: bought.reason,
    outcome: `Swap executed · gas ${gasOf(bought)}`,
  },
};

export const MOMENT_ORDER: readonly MomentId[] = ["sat", "thu"];
```

```tsx
function svgDoc(body: string): string {
  return `<svg xmlns="http://www.w3.org/2000/svg" width="30" height="30" viewBox="0 0 30 30">${body}</svg>`;

function glyph(fg: string, feather: string): string {

  return (
    `<path d="${MARK.beam}" fill="none" stroke="${fg}" stroke-width="${MARK.beamWidth}" stroke-linecap="round"/>` +
    `<path d="${MARK.feather}" fill="${feather}"/>` +
    `<rect x="${o.x}" y="${o.y}" width="${o.size}" height="${o.size}" rx="${o.radius}" fill="${fg}"/>`
  );
}

/** dark: the site mark. light: outlined tile for white backgrounds. */

  if (variant === "dark") {

  );
}

/** Full-bleed tile for the X avatar and Apple touch icon; those platforms crop or round it themselves. */

  );
}

const dataUri = (svg: string) => `data:image/svg+xml;base64,${Buffer.from(svg).toString("base64")}`;
const png = (svg: string, width: number): Buffer =>
  new Resvg(svg, { fitTo: { mode: "width", value: width } }).render().asPng();

export function pngSize(buf: Buffer): { width: number; height: number } {
  if (buf.readUInt32BE(0) !== 0x89504e47) throw new Error("not a PNG");
  return { width: buf.readUInt32BE(16), height: buf.readUInt32BE(20) };
}

/** A one-image .ico that embeds the PNG as is (supported by every current browser). */
export function pngToIco(pngData: Buffer, size: number): Buffer {
  const header = Buffer.alloc(6);
  header.writeUInt16LE(0, 0);
  header.writeUInt16LE(1, 2);
  header.writeUInt16LE(1, 4);
  const entry = Buffer.alloc(16);
  entry.writeUInt8(size >= 256 ? 0 : size, 0);
  entry.writeUInt8(size >= 256 ? 0 : size, 1);
  entry.writeUInt16LE(1, 4);
  entry.writeUInt16LE(32, 6);
  entry.writeUInt32LE(pngData.length, 8);
  entry.writeUInt32LE(header.length + entry.length, 12);
  return Buffer.concat([header, entry, pngData]);
}
```

```ts
type Env = Record<string, string | undefined>;

/** Absolute base for OG/Twitter URLs: NEXT_PUBLIC_SITE_URL, then the Vercel production domain, then localhost. */
export function siteUrl(env: Env = process.env): URL {
  const explicit = env.NEXT_PUBLIC_SITE_URL?.trim();
  if (explicit) return new URL(explicit);
  const vercel = env.VERCEL_PROJECT_PRODUCTION_URL?.trim();
  if (vercel) return new URL(`https://${vercel}`);
  return new URL("http://localhost:3000");
}
```

`web/lib/check-out.ts`:

```ts
import { MOMENTS } from "../content/engine";
import { SITE } from "./site";

/** Problems with the exported landing page; an empty list means it is ready to ship. */
export function checkExport(html: string): string[] {
  const problems: string[] = [];
  const need = (ok: boolean, problem: string) => {
    if (!ok) problems.push(problem);
  };

  need(html.includes('<html lang="en"'), 'missing <html lang="en">');
  need(html.includes(`<title>${SITE.title}</title>`), "title does not match SITE.title");
  need(html.includes(`<meta name="description" content="${SITE.description}"/>`), "meta description does not match SITE.description");
  const og = /<meta property="og:image" content="([^"]+)"/.exec(html)?.[1];
  need(og !== undefined && /^https?:\/\//.test(og), "og:image is missing or not an absolute URL");
  need(html.includes('<meta name="twitter:card" content="summary_large_image"/>'), "twitter:card is not summary_large_image");
  need(html.includes(`<meta name="twitter:site" content="${SITE.xHandle}"/>`), "twitter:site is not the X handle");

  // Crawlers, link previews and no-JS readers never hydrate: the default moment must be in the HTML itself.
  // The verdict is read from the live region's own card; the text "Refused" alone also matches a ledger filter chip.
  const sat = MOMENTS.sat;
  const verdict = sat.allowed ? "allowed" : "refused";
  need(
    new RegExp(`aria-pressed="true"[^>]*>${sat.toggleLabel}<`).test(html),
    `${sat.toggleLabel} is not the pressed moment in the exported HTML`,
  );
  need(
    new RegExp(`role="status"[^>]*><div[^>]*\\sdata-verdict="${verdict}"[^>]*\\sdata-reason="${sat.reason}"`).test(html),
    `the ${sat.toggleLabel} verdict (${verdict} · ${sat.reason}) is not in the exported HTML`,
  );

  for (const [, id] of html.matchAll(/<a[^>]*\shref="#([^"]+)"/g)) {
    need(html.includes(` id="${id}"`), `link #${id} has no target`);
  }
  for (const [, src] of html.matchAll(/<script[^>]*\ssrc="([^"]+)"/g)) {
    need((src ?? "").startsWith("/_next/"), `third-party script: ${src}`);
  }
  need(!/fonts\.(googleapis|gstatic)\.com/.test(html), "the page loads Google Fonts at runtime");
  return problems;
}
```

```ts
import { expect, type Page, test } from "@playwright/test";

const WIDTHS = [360, 768, 1440, 1920] as const;

function collectErrors(page: Page): string[] {
  const errors: string[] = [];
  page.on("console", (m) => {
    if (m.type() === "error") errors.push(m.text());
  });
  page.on("pageerror", (e) => errors.push(e.message));
  return errors;
}

for (const width of WIDTHS) {
  test(`fits ${width}px: no page scroll, nothing clipped, no console errors`, async ({ page }) => {
    const errors = collectErrors(page);
    await page.setViewportSize({ width, height: 900 });
    await page.goto("/");
    await page.evaluate(() => document.fonts.ready);
    const fit = await page.evaluate(() => ({
      overflow: document.documentElement.scrollWidth - window.innerWidth,
      clipped: [...document.querySelectorAll<HTMLElement>(".card")]
        .filter((el) => !el.hasAttribute("data-scroll-x") && el.scrollWidth > el.clientWidth + 1)
        .map((el) => (el.textContent ?? "").trim().slice(0, 60)),
    }));
    expect(fit.overflow).toBeLessThanOrEqual(0);
    expect(fit.clipped).toEqual([]);
    expect(errors).toEqual([]);
    await page.screenshot({ path: `test-results/screens/landing-${width}.png`, fullPage: true });
  });
}

test("the moment toggle works by mouse and keyboard", async ({ page }) => {
  await page.goto("/");
  const verdict = page.getByRole("status");
  const thu = page.getByRole("button", { name: "Thu 5 Nov · 10:30" });
  const sat = page.getByRole("button", { name: "Sat 7 Nov" });
  await expect(verdict).toContainText("Refused");
  await expect(verdict).toContainText("MARKET_CLOSED");

  await thu.click();
  await expect(verdict).toContainText("Allowed");
  await expect(thu).toHaveAttribute("aria-pressed", "true");

  await sat.focus();
  await page.keyboard.press("Enter");
  await expect(verdict).toContainText("Refused");
  await expect(sat).toHaveAttribute("aria-pressed", "true");
});

test("the ledger filters", async ({ page }) => {

  await expect(rows).toHaveCount(4);
  await page.getByRole("button", { name: "Refused", exact: true }).click();
```
